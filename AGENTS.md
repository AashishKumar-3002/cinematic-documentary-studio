# Studio guidance

- The primary production workflow is `.agents/skills/cinematic-film/SKILL.md`. HyperFrames and the other bundled skills support it when appropriate.
- All 18 project skills are under `.agents/skills/`; `docs/SKILLS.md` describes their prerequisites and sources.
- For a new documentary, read `projects/production-profile.json` and the saved user feedback in the documentary-production-playbook. Treat tutorial styles as flexible references; emphasize engaging writing, narration-timed visual actions and purposeful sound.
- Keep the free local baseline. Optional paid generation services require a user-provided budget/authorization.
- Keep dependencies, caches, models and downloaded research inside this workspace and outside Git. Preserve source licences and media attribution.
- The existing Lake Nyos film is a reviewed learning example. Do not recreate it merely because the feedback or a style skill is loaded.
- Publishing helpers perform real external actions when explicitly invoked. A repository clone or skill load does not authorize uploads, scheduling or messages.
